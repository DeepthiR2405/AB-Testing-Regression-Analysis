End-to-end A/B testing and regression analysis project evaluating Facebook vs Google AdWords campaign performance. Applied hypothesis testing, trend analysis, and predictive modeling to identify the best-performing platform and provide data-driven marketing recommendations.

# A/B Testing & Regression Analysis – Marketing Campaign Performance

## 📌 Project Overview
This project evaluates the performance of two digital advertising platforms — Facebook Ads and Google AdWords — using A/B testing and regression analysis.

The goal is to identify the better-performing platform and understand how ad spend impacts conversions.

## 🧠 Key Objectives
- Perform A/B testing to compare platform conversion performance
- Conduct hypothesis testing for statistical significance
- Analyze weekly and monthly performance trends
- Apply regression analysis to predict conversions based on ad spend
- Present insights in a business-friendly manner

## 📊 Dataset
- Synthetic dataset generated to simulate real-world marketing campaigns
- Daily performance data for Facebook and Google AdWords (2019)
- Metrics include views, clicks, conversions, cost, CTR, CPC

## 🛠 Tools & Technologies
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- SciPy (A/B Testing)
- Statsmodels (Regression Analysis)
- Jupyter Notebook

## 📈 Key Insights
- Google AdWords outperformed Facebook in average daily conversions
- A/B testing confirmed statistically significant performance difference
- Regression analysis showed stronger conversion efficiency for AdWords
- Monthly trends indicate consistent scalability for AdWords campaigns

## 📌 Business Recommendation
Allocate higher budget to Google AdWords for improved conversion efficiency while maintaining Facebook for awareness-driven campaigns.
